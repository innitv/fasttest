# Приёмка демо

Запускай из корня репозитория с Node.js 22+, Yarn 1 и Chromium для Playwright.
Для установки браузера используется `yarn playwright install chromium`.

1. Выполни `yarn build`. При сбое сборки остановись и разберись с её выводом.
2. Выполни `yarn check:theme`, `yarn check:motion`, `yarn check:docs` и
   `yarn check:registry`. Для всех четырёх достаточно файлов репозитория.
3. Запусти `yarn preview --strictPort` в отдельном терминале или через действие
   **Preview · 4319** в Codex. Дождись успешного HTTP-ответа
   `http://127.0.0.1:4319/`. Если порт занят, используй другой свободный порт
   с флагом `--port` и передай этот же адрес всем трём браузерным проверкам.
4. Выполни по порядку `yarn verify --base=<адрес>`,
   `yarn check:mobile --base=<адрес>` и `yarn check:visual --base=<адрес>`.
   При сбое одной проверки сохрани её вывод и прогони остальные.
5. Останови только свой preview даже при сбое. Проверь, что его порт больше
   не отвечает. Скриншоты и отчёты сохраняй в `test-results/`.

Сверь охват новой темы с `ROUTES` в `tests/mobile.check.mjs`, включая
ожидание наличия полей. Визуальные эталоны обновляй только после согласования
изменения кадра. Для сверки с разрешённым референсом используй
`yarn donor:compare` по навыку `$donor-capture`.

В отчёте укажи фактические результаты и exit-коды, числа из вывода команд,
пути к артефактам и конкретные причины пропусков или падений.
